# Keyano

Keyano là ứng dụng web (PWA) để chơi piano bằng bàn phím máy tính — và sau này trên điện thoại.

## Lệnh

```bash
npm install      # cài dependencies
npm run dev      # chạy dev server
npm test         # chạy test (vitest)
npm run lint     # kiểm tra lint
npm run typecheck
npm run build    # build production ra dist/
```

## Deploy (Vercel)

Import repo `hung1203/keyano` trên Vercel — framework **Vite** được tự nhận, output `dist`. Không cần cấu hình thêm.
